# LeetCode Solutions

A collection of my accepted **LeetCode** solutions implemented in **C++**.

The purpose of this repository is to improve my problem-solving skills, strengthen my understanding of **Data Structures & Algorithms**, and prepare for technical interviews and software engineering placements.

---

## Repository Structure

Problems are organized by topic.

```text
LeetCode-Solutions/
│
├── Arrays/
├── Strings/
├── Linked List/
├── Stack/
├── Queue/
├── Binary Search/
├── Recursion/
├── Backtracking/
├── Trees/
├── Graphs/
├── Dynamic Programming/
├── Greedy/
├── Heap/
├── Trie/
└── ...
```

Each problem is stored in its own folder.

Example:

```text
Backtracking/
└── 0046-Permutations/
    ├── solution.cpp
    └── README.md
```

---

## Contents of Each Problem

Every problem folder contains:

- `solution.cpp` – Accepted C++ solution.
- `README.md` – Problem summary, approach, and complexity analysis.
